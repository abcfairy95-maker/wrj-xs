# 参数定义（One Click / Control Point Routing）

## One Click Routing 参数

| 符号 | 名称 | 范围/格式 | 默认值 | 算法含义 |
|---|---|---|---|---|
| d | 避障距离 | 0 < d ≤ 10，整数 | 6 | 线束外圆周表面到障碍物实体的绝对硬约束距离（mm）|
| d_b | 分支线径 | 0 < d_b ≤ 10，1位小数 | 6 | 末端分支及单终点情况的基准渲染线径 |
| D_t | 主干线径 | d_b < D_t ≤ 50，1位小数 | 12 | 容纳电线股数最多段的系统最大渲染线径 |
| r | 最小转弯半径倍数 | 0 < r ≤ 3，整数 | 2 | 实际最小转弯半径 R = r × D_seg |
| l1 | 末端最小分支长度 | 0 < l1 ≤ 100，整数 | 60 | 终点到最近分叉点的中心线长度硬约束 |
| l2 | 分支点最小距离 | 0 < l2 ≤ 100，整数 | 75 | 相邻分叉点之间的中心线弧长约束 |
| x | 最大单点分支数量 | 4 或 5 | 4 | 单个分叉点允许分出的最大线束段数量上限 |
| l3 | 卡扣最小距离 | 60 < l3 ≤ 150 | 100 | 相邻卡扣间最小间距 |
| l4 | 卡扣最大距离 | l3 < l4 ≤ 300 | 150 | 超出此间距必须自动补加补充卡扣 |
| l5 | 卡扣到分支点最小距离 | 30 ≤ l5 ≤ 60 | 40 | 卡扣与分叉点之间的安全避让硬约束 |
| l6 | 卡扣到起终点最小距离 | ≥ 60 | 60 | 最近卡扣至起点/终点的中心线距离 |

## Control Point Routing 参数

| 符号 | 名称 | 范围/格式 | 默认值 | 算法含义 |
|---|---|---|---|---|
| d | 避障距离 | 0 < d ≤ 10 | 6 | 线束外圆周表面到障碍物实体的绝对硬约束距离 |
| D_t | 主干线径 | 0 < D_t ≤ 50，1位小数 | 12 | 全段线径直接等于 D_t |
| r | 最小转弯半径倍数 | 0 < r ≤ 6 | 2 | 实际最小转弯半径 R = r × D_t |
| l3 | 卡扣最小距离 | 60 < l3 ≤ 150 | 100 | 相邻卡扣间最小间距 |
| l4 | 卡扣最大距离 | l3 < l4 ≤ 300 | 150 | 超出必须补加补充卡扣 |
| l6 | 卡扣到起终点最小距离 | ≥ 60 | 60 | 最近卡扣至起点/终点的中心线距离 |

## 回退策略（One Click，6 级）

| 层级 | 触发条件 | 回退动作 |
|---|---|---|
| 理想 | 无冲突 | 贴面+避障 d+禁止侵入避让区+半径 r 全满足 |
| 一级 | 终点不可达 | 放开贴面，允许脱离优先布线区 |
| 二级 | 仍不可达 | 避障距离 = d × 50% |
| 三级 | 仍不可达 | 避障距离 = 0，允许接触障碍物 |
| 四级 | 仍不可达 | 允许进入避让区 |
| 五级 | 仍不可达 | 半径 = r × 50%，避障 = 0 |
| 六级 | 仍不可达 | 完全放开转弯半径（允许尖角），避障 = 0 |
| 最终失败 | 六级后不可达 | 返回失败结果，列出未连接目标点 |
